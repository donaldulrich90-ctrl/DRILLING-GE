Présentation de la plateforme

1.1 À quoi sert GEDRILLING ?

GEDRILLING (Good Engineers Drilling) est une application web complète conçue pour les entreprises spécialisées dans le forage minier. Elle centralise en un seul outil toute la gestion opérationnelle, administrative et financière des chantiers de forage.

La plateforme s'adresse à plusieurs profils :

  • Direction / Administration : suivi financier, facturation, contrats, tableaux de bord
  • Chefs de chantier : pilotage des foreuses, assignations, maintenance, plan de forage
  • Opérateurs foreurs : saisie journalière des données de production
  • RH / Comptabilité : gestion du personnel, fiches de paie, stocks
  • HSE : suivi sécurité, incidents, formations
ℹ️
Avantage clé Toutes les données sont centralisées dans une base SQLite locale ou sur un serveur. Plusieurs utilisateurs peuvent se connecter simultanément depuis n'importe quel navigateur sur le réseau local ou via Internet.

1.2 Architecture technique

ComposantTechnologieRôle
Serveur APINode.js + ExpressTraite toutes les requêtes, authentification JWT
Base de donnéesSQLite 3Stockage de toutes les données (fichier database.db)
Interface webHTML5 + Tailwind CSSPage principale plateforme-forage.html
GraphiquesChart.jsVisualisations de performance et revenus
AuthentificationJWT (JSON Web Token)Sessions sécurisées, expiration 7 jours
⚠️
Important L'application ne peut pas fonctionner en ouvrant simplement le fichier plateforme-forage.html par double-clic. Le serveur Node.js doit être démarré au préalable pour que l'API fonctionne.

Installation et démarrage

2.1 Prérequis

LogicielVersion minimaleTéléchargement
Node.js16 ou supérieurehttps://nodejs.org
Navigateur webChrome, Firefox, Edge (récent)—

Pour vérifier que Node.js est installé, ouvrez un terminal et tapez :

node --version
npm --version

Ces commandes doivent afficher un numéro de version. Si ce n'est pas le cas, installez Node.js depuis nodejs.org.

2.2 Lancement rapide sous Windows

  1. 1
    Double-cliquez sur LANCER.bat
    Ce fichier se trouve dans le dossier du projet. Il installe automatiquement les dépendances et démarre le serveur.
  2. 2
    Une fenêtre noire s'ouvre
    Attendez le message ✅ Serveur démarré sur le port 3000. Ne fermez pas cette fenêtre.
  3. 3
    Ouvrez votre navigateur
    Accédez à l'adresse : http://localhost:3000
✅
Conseil Si le serveur affiche ⚠️ Base de données non trouvée, exécutez d'abord npm run init-db dans le terminal depuis le dossier du projet.

2.3 Lancement manuel (terminal)

Ouvrez un terminal dans le dossier du projet et exécutez ces commandes dans l'ordre :

# Étape 1 : installer les dépendances (une seule fois)
npm install

# Étape 2 : créer la base de données (une seule fois)
npm run init-db

# Étape 3 : démarrer le serveur
npm start

Pour le développement (rechargement automatique) :

npm run dev

L'application est alors accessible sur http://localhost:3000.

  • Répartition des contrats : par client et par site

Actualisation automatique

Foreuses et connexions

Le module Connexions centralise la gestion de toutes les machines de forage (foreuses, sondeuses) de l'entreprise.

Liste des foreuses

Chaque foreuse est représentée par une carte affichant :

  • Le nom / identifiant de la machine
  • Le modèle et le numéro de série
  • Le site d'affectation actuel
  • Le statut : Active, En maintenance, Hors service
  • L'opérateur assigné

Ajouter une foreuse

  1. 1
    Cliquez sur « Ajouter une foreuse »
    Le bouton se trouve en haut à droite de la liste.
  2. 2
    Remplissez le formulaire
    Champs requis : nom de la machine, modèle, numéro de série, site d'affectation, statut initial.
  3. 3
    Enregistrez
    La foreuse apparaît immédiatement dans la liste.

Modifier ou supprimer une foreuse

Cliquez sur la carte de la foreuse pour ouvrir sa fiche détaillée. Vous pouvez y :

  • Modifier les informations (modèle, site, statut)
  • Consulter l'historique de maintenance
  • Voir les assignations en cours et passées
  • Supprimer la machine (action irréversible — les données liées sont conservées)

Statuts de machine

StatutSignificationImpact
ActiveMachine en service, opérations normalesComptabilisée dans la production
En maintenanceArrêt planifié ou curatifSignalée dans les alertes du tableau de bord
Hors serviceIndisponible (panne grave, attente pièce)Exclue du calcul de disponibilité

Assignations

Le module Assignations (accessible depuis la barre latérale) permet de lier un opérateur à une foreuse pour une période définie :

  1. 1
    Cliquez sur « Nouvelle assignation »
  2. 2
    Sélectionnez la foreuse, l'opérateur, le site et les dates de début/fin
  3. 3
    Enregistrez — l'assignation apparaît dans le calendrier et la fiche de la foreuse.
⚠️
Conflits d'assignation
Le système détecte automatiquement si un opérateur est déjà assigné à une autre machine sur la même période et affiche un avertissement.

Contrats

Le module Contrats gère le cycle de vie complet des accords commerciaux avec vos clients : de la création à la clôture, en passant par le suivi de l'avancement.

Informations d'un contrat

ChampDescription
Numéro de contratRéférence unique générée automatiquement ou saisie
ClientEntreprise cliente (choisie dans le répertoire)
SiteChantier concerné par ce contrat
Date de début / finDurée prévue du contrat
Type de prestationForage au mètre, à la journée, forfait…
Prix unitaireTarif par mètre foré ou par jour de prestation
Quantité contractéeNombre de mètres ou de jours prévus
Montant totalCalculé automatiquement (prix × quantité)

Créer un contrat

  1. 1
    Accédez à Gestion des Contrats dans la barre latérale.
  2. 2
    Cliquez sur « Nouveau contrat ».
  3. 3
    Sélectionnez le client et le site, renseignez les dates, le type de prestation et le prix unitaire.
  4. 4
    Enregistrez. Le contrat est immédiatement disponible pour la facturation.

Suivi de l'avancement

Pour chaque contrat, GEDRILLING calcule automatiquement :

  • Mètres réalisés : somme des saisies journalières liées à ce contrat
  • Taux d'avancement : (réalisé / contracté) × 100 %
  • Montant facturé : total des factures émises sur ce contrat
  • Reste à facturer : différence entre la valeur contractuelle et le facturé
⚠️
Alerte fin de contrat
Le tableau de bord signale automatiquement les contrats qui arrivent à expiration dans les 30 jours ou dont l'avancement dépasse 90 %.

Facturation

Le module Factures permet de créer, envoyer et suivre toutes les factures de l'entreprise. Les factures sont liées aux contrats et peuvent être exportées en PDF.

Créer une facture

  1. 1
    Ouvrez le module Factures depuis la barre latérale.
  2. 2
    Cliquez sur « Nouvelle facture »
  3. 3
    Sélectionnez le client et le contrat
    Les informations du client (adresse, devise) sont remplies automatiquement.
  4. 4
    Ajoutez les lignes de facturation
    Chaque ligne comprend : description, quantité, prix unitaire, TVA (optionnel).
  5. 5
    Vérifiez le total HT / TVA / TTC
    Calculé automatiquement.
  6. 6
    Enregistrez — statut initial : Émise.

Statuts des factures

StatutDescription
BrouillonFacture en cours de préparation, non envoyée
ÉmiseFacture envoyée au client, paiement en attente
PayéePaiement reçu et enregistré
En retardDate d'échéance dépassée sans paiement
AnnuléeFacture invalidée (avoir émis)

Imprimer / exporter en PDF

  1. 1
    Ouvrez la facture souhaitée en cliquant dessus dans la liste.
  2. 2
    Cliquez sur le bouton « Imprimer » ou « Voir PDF ».
  3. 3
    La facture s'ouvre dans une fenêtre d'aperçu. Utilisez Ctrl+P → Enregistrer en PDF dans votre navigateur.

La facture PDF inclut : logo de l'entreprise, coordonnées client, lignes détaillées, totaux HT/TVA/TTC, conditions de paiement, mentions légales.

Enregistrer un paiement

Une fois le paiement reçu, ouvrez la facture et cliquez sur « Marquer comme payée ». Vous pouvez saisir la date de paiement, le mode (virement, chèque, espèces) et une référence bancaire.

Module Consommables

Ce module suit la consommation des fournitures liées aux opérations de forage. Chaque sortie de stock est liée à une foreuse et à une date.

Type de consommableExemples
Outillage de fondTrépans (bits), couronnes, stabilisateurs
Tiges et équipementsTiges de forage, massettes, raccords
Fluides et produitsEau, bentonite, additifs de boue
ÉnergieCarburant (gasoil), lubrifiants
Consommables diversFiltres, joints, pièces d'usure

Module Stocks

Le module Stocks (accessible via Stocks dans la barre latérale) gère l'inventaire physique de l'entreprise :

  • Entrées de stock : réception de commandes fournisseurs
  • Sorties de stock : consommation sur chantier, casse, perte
  • Niveau de stock : quantité disponible en temps réel
  • Seuil d'alerte : notification lorsque le stock passe sous un seuil minimum
  • Valorisation : valeur monétaire du stock (FIFO ou prix moyen)

Enregistrer une entrée ou sortie de stock

  1. 1
    Accédez à Stocks dans la barre latérale.
  2. 2
    Cliquez sur « Nouvelle entrée » ou « Nouvelle sortie ».
  3. 3
    Sélectionnez l'article, saisissez la quantité, la date et éventuellement la foreuse ou le site concerné.
  4. 4
    Enregistrez. Le stock est mis à jour en temps réel.

Maintenance

Le module Maintenance gère l'entretien préventif et correctif de toutes les machines de l'entreprise. Un bon suivi de la maintenance prolonge la durée de vie des équipements et réduit les arrêts imprévus.

Types de maintenance

TypeDescriptionPlanification
PréventiveEntretien planifié avant la pannePar heure-machine ou par date calendaire
CorrectiveRéparation suite à une panne ou défaillanceÀ la demande, suite à un incident
RéglementaireContrôle obligatoire (vérification annuelle, etc.)Par date légale

Planifier une intervention

  1. 1
    Accédez au module Maintenance.
  2. 2
    Cliquez sur « Planifier une maintenance ».
  3. 3
    Sélectionnez la foreuse, le type d'intervention, la date prévue et le technicien responsable.
  4. 4
    Saisissez les opérations à réaliser et les pièces nécessaires (liées au stock).
  5. 5
    Enregistrez. L'intervention apparaît dans le planning et génère une alerte sur le tableau de bord.

Enregistrer une intervention réalisée

Après l'exécution d'une maintenance, ouvrez l'ordre de travail et renseignez :

  • Date et heure réelles de début et de fin
  • Technicien(s) ayant réalisé l'intervention
  • Pièces remplacées (sorties de stock automatiquement)
  • Coût total de l'intervention (main-d'œuvre + pièces)
  • Observations et recommandations

Le statut passe automatiquement à Terminée et l'historique est conservé pour analyse.

Alertes de maintenance

🔔
Alertes automatiques
GEDRILLING génère des alertes lorsqu'une maintenance prévue approche (J-7, J-1) ou est dépassée. Ces alertes apparaissent sur le tableau de bord et peuvent déclencher des notifications.

Plan de Forage

Le module Plan de Forage est l'outil de planification du programme de trous à forer. Il permet de définir le patron de forage, puis de suivre l'avancement trou par trou.

Créer un plan de forage

  2. 2

  3. 3

  4. 4
    Importez ou saisissez manuellement les trous : identifiant, coordonnées, profondeur cible, azimut, inclinaison.
  5. 5
    Enregistrez le plan.

Suivi de l'avancement

Pour chaque trou du plan, vous pouvez enregistrer :

ChampDescription
StatutPrévu / En cours / Terminé / Abandonné
Profondeur atteinteMètres réellement forés
Date de début / finChronologie réelle du trou
ObservationsIncidents, variations géologiques, déviations

Un indicateur visuel (vert / orange / rouge) permet de voir d'un coup d'œil l'état du programme de forage.

Export du plan

Le plan de forage peut être exporté en PDF pour transmission au client ou à l'équipe terrain. Le document inclut la liste des trous avec leurs paramètres et l'état d'avancement à la date d'export.

Pilotage projet et Performance

Pilotage projet

Le module Pilotage projet offre une vue de synthèse pour les responsables et chefs de projet. Il consolide les données opérationnelles de tous les chantiers en cours.

IndicateurDescription
Avancement global% réalisé vs. objectif contractuel

Taux de disponibilité(Heures productives / Heures totales) × 100

Module Performance (Analytics)

Le module Performance analyse les indicateurs opérationnels en détail :

  • ROP (Rate of Penetration) : vitesse de pénétration en m/h, par foreuse et par période
  • Temps non-productifs (TNP) : répartition des arrêts — panne, météo, attente logistique, congé
  • Graphiques temporels : évolution de la ROP sur 24h, 7 jours, 30 jours
  • Comparaison inter-foreuses : identification des écarts de performance
💡
Utilisation
Analysez la ROP pour identifier les formations géologiques difficiles ou les problèmes d'outillage. Un TNP élevé peut indiquer un problème d'organisation ou d'approvisionnement à corriger.

Rentabilité et Dépenses PM

Rentabilité Consommables

Ce module calcule le coût réel des consommables par mètre foré, afin d'identifier les postes de dépenses excessifs et d'optimiser les achats.

MétriqueFormule
Coût/mètre (trépan)Coût total des trépans ÷ Mètres forés
Coût/mètre (carburant)Consommation carburant × Prix litre ÷ Mètres forés
Coût/mètre (total)Somme de tous les consommables ÷ Mètres forés
Durée de vie trépanMètres forés par trépan (optimisation des achats)

Gestion multi-entreprises

GEDRILLING supporte deux modes de déploiement pour s'adapter à votre organisation :

Mode dédié (par défaut)

Une instance du serveur = une entreprise. C'est le mode recommandé pour la plupart des utilisations. Chaque client dispose de son propre serveur (ou conteneur Docker) avec sa propre base de données.

✅
Avantages
Isolation totale des données. Performance optimale. Simplicité d'administration. Mise à jour indépendante par client.

Mode partagé (multi-tenant)

Une seule installation héberge plusieurs entreprises clientes. Le compte gestion_abonnements (rôle platform_owner) gère toutes les entreprises depuis l'onglet Entreprises.

ActionComment
Créer une nouvelle entreprise clienteOnglet Entreprises → Nouvelle entreprise → définir nom, plan, quotas
Définir les modules accessiblesSélectionner les onglets autorisés dans le plan de l'entreprise
Créer les utilisateurs clientsOnglet Comptes → associer l'enterpriseId correspondant
Suspendre un clientOnglet Entreprises → passer le statut à Inactif
Basculer entre entreprisesMenu déroulant "Entreprise" dans l'en-tête

Isolation des données

Chaque utilisateur ne voit que les données de son entreprise. L'isolation est garantie par le serveur côté API : toutes les requêtes filtrent sur l'enterpriseId issu du token JWT. Un utilisateur d'une entreprise A ne peut jamais accéder aux données d'une entreprise B.

Fiche opérateur — Saisie journalière

La fiche opérateur (fiche-operateur-saisie-journaliere.html) est un formulaire A4 imprimable destiné aux foreurs sur le terrain. L'opérateur la remplit à la main en fin de poste, et les données sont ensuite ressaisies dans la plateforme.

Sauvegarde et restauration

La base de données est le cœur de GEDRILLING. Il est impératif de la sauvegarder régulièrement pour éviter toute perte de données.

Sauvegarder la base de données

Ouvrez un terminal dans le dossier du projet et exécutez l'une des commandes suivantes :

CommandeAction
npm run backupSauvegarde rapide — copie du fichier SQLite dans le dossier backups/
npm run backup:fullSauvegarde complète avec compression (recommandé)
npm run backup:listListe toutes les sauvegardes disponibles avec leur date
npm run backup:pruneSupprime les sauvegardes anciennes (conserve les N plus récentes)
npm run backup:full

La sauvegarde est stockée dans le sous-dossier backups/ avec un nom incluant la date et l'heure : backup-2025-06-15-14h30.db.gz

Restaurer une sauvegarde

🔴
Attention
La restauration remplace la base de données actuelle par la sauvegarde choisie. Toutes les données enregistrées après la sauvegarde seront perdues. Effectuez toujours une sauvegarde avant de restaurer.
  1. 1
    Arrêtez le serveur (fermez la fenêtre du terminal ou Ctrl+C).
  2. 2
    Exécutez npm run restore-backup. Le script affiche la liste des sauvegardes disponibles.
  3. 3
    Saisissez le numéro de la sauvegarde à restaurer et confirmez.
  4. 4
    Redémarrez le serveur : npm start.

Recommandations

  • Effectuez une sauvegarde quotidienne (automatisez via le Planificateur de tâches Windows ou cron Linux)
  • Conservez des copies sur un disque externe ou dans le cloud (ne pas stocker uniquement sur le même serveur)
  • Testez périodiquement la restauration pour valider l'intégrité des sauvegardes
  • Sauvegardez toujours avant une mise à jour de la plateforme

Déploiement avec Docker

docker-compose up -d --build

# Windows

  1. 1

  3. 3

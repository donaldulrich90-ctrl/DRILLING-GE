GEDRILLING

Installation du serveur LOCAL (au site, sans internet)

Fiche d'installation — à suivre une seule fois sur le PC/serveur du site.

But : faire tourner la plateforme au site, sans internet. Les tablettes et PC du site s'y connectent par le réseau local (WiFi/LAN). Quand internet revient, le serveur local se synchronise tout seul avec le serveur en ligne (données + configuration).

Avant de commencer

Il vous fautDétail
Un PC/serveur au siteWindows, allumé en permanence. Installez Node.js 20 (LTS) depuis nodejs.org (cliquez « Suivant » partout). Git (git-scm.com) est recommandé pour les mises à jour.
Le dossier du logicielLe code de la plateforme (dossier DRILLING-GE) copié sur ce PC (GitHub → Code → Download ZIP, puis dézipper). Les dépendances s'installent toutes seules au 1er démarrage.
3 informationsL'adresse du serveur en ligne, et un compte administrateur (identifiant + mot de passe) de votre entreprise sur ce serveur.

Étapes

  1. Récupérer les données du serveur en ligne
    Sur le serveur en ligne, connecté en admin de l'entreprise : vue Comptes → panneau Synchronisation → « ⬇️ Télécharger la base (seed.db) ». Vous obtenez directement le fichier seed.db.
    (Le propriétaire de la plateforme peut aussi faire Entreprises → « Télécharger une sauvegarde », puis renommer le fichier en seed.db.)
    Placez seed.db à la racine du dossier du logiciel sur le PC du site.
    Ainsi le local démarre déjà avec tous vos sites, foreuses, fosses, contrats, comptes et données — rien à ressaisir.
  2. Créer le fichier de configuration
    Faites une copie du fichier .env.local.example et nommez-la .env.local. Ouvrez-la et remplissez :
    LigneÀ mettre
    SYNC_REMOTE_URLL'adresse du serveur en ligne (ex. https://forage.waudrilling.com)
    SYNC_USERNAMEUn compte admin de votre entreprise en ligne
    SYNC_PASSWORDLe mot de passe de ce compte
    Les autres lignes (fréquence, port) peuvent rester telles quelles.
  3. Démarrer le serveur local
    Dans le dossier du logiciel, lancez : ./scripts/start-local.sh
    Sous Windows (PowerShell) : scripts\start-local.ps1. Au premier démarrage, il charge seed.db puis active la synchro automatique.
  4. Connecter les appareils du site
    Notez l'adresse IP du PC serveur sur le réseau du site. Sur les tablettes/PC, ouvrez le navigateur à : http://ADRESSE-IP-DU-SERVEUR:3000
    Exemple : http://192.168.1.50:3000. Tous les appareils doivent être sur le même WiFi/réseau que le serveur.
  5. Vérifier la synchronisation
    Connectez-vous en admin → vue Comptes → panneau « 🔄 Synchronisation local ⇄ en ligne ». La ligne de statut indique « activée » et la dernière synchro. Bouton « Synchroniser maintenant » pour forcer un cycle quand il y a internet.

✅ Au quotidien

On travaille toujours sur le serveur local (saisies, patterns, rapports), même sans internet. Dès qu'internet revient, les données remontent en ligne automatiquement et la config descend de la ligne.

🔄 Mettre à jour le logiciel

Quand il y a internet, lancez : ./scripts/update.sh Récupère la dernière version et redémarre sans toucher à la base (dossier data).

Pas de WiFi au site ? Utiliser le PC comme point d'accès (Windows)

Le PC serveur peut créer son propre WiFi ; les tablettes s'y connectent (aucun internet nécessaire).
  1. Activer le point d'accès
    Paramètres → Réseau et Internet → Point d'accès sans fil. Cliquez Modifier pour mettre un nom (GEDRILLING) et un mot de passe (8 caractères mini), puis activez.
    Si Windows refuse (« pas de connexion à partager »), ouvrez l'invite de commandes en administrateur et tapez :
    netsh wlan set hostednetwork mode=allow ssid=GEDRILLING key=motdepasse123 netsh wlan start hostednetwork
  2. Trouver l'IP du PC & autoriser le port
    Tapez ipconfig → l'IPv4 du point d'accès est en général 192.168.137.1. Autorisez le port 3000 : netsh advfirewall firewall add rule name="GEDRILLING 3000" dir=in action=allow protocol=TCP localport=3000
  3. Connecter les tablettes
    Démarrez le serveur, puis sur les tablettes : WiFi GEDRILLING → navigateur sur http://192.168.137.1:3000.
    Gardez le PC allumé et désactivez sa mise en veille pendant le poste.

En cas de souci

SymptômeÀ faire
Le statut synchro affiche une erreur de connexionVérifiez l'adresse (SYNC_REMOTE_URL) et le mot de passe dans .env.local, et qu'internet est disponible.
Une tablette n'ouvre pas la pageVérifiez qu'elle est sur le même WiFi et que l'IP + :3000 sont corrects.
Besoin de repartir des données en ligneRe-téléchargez une sauvegarde, remplacez data/database.db par ce fichier, puis redémarrez.
